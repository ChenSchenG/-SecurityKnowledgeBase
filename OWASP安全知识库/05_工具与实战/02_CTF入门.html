CTF 入门与实战

CTF（Capture The Flag，夺旗赛）是信息安全领域最受欢迎的技术竞赛形式。通过解决各类安全挑战来获取 Flag（通常格式为 flag{...}），是提升安全技能最高效的方式之一。

学习目标
  • 理解 CTF 的比赛形式与题目分类
  • 掌握 Web、Crypto、Forensics、Reverse 各方向的基础解题思路
  • 熟悉常用 CTF 平台和练习资源
  • 建立系统化的学习路径

1.2 Jeopardy 模式详解

Jeopardy 是最常见的 CTF 形式，题目按类别和难度分布：

难度分值特征适合人群
Easy100-200单一知识点，直接利用初学者
Medium200-400多知识点组合，需要分析有基础者
Hard400-600复杂利用链，需深入理解进阶选手
Insane600+0day级别，极少人能解高手/出题者水平
动态积分制

现代 CTF 多采用动态积分：题目初始分值较高，随着解出人数增加分值下降。这鼓励选手尝试难题，同时避免签到题分值与难题相同的不公平。

# === 古典密码 Python 解题 ===

# Caesar Cipher 暴力破解
def caesar_brute(ciphertext):
    for shift in range(26):
        plaintext = ""
        for char in ciphertext:
            if char.isalpha():
                base = ord('A') if char.isupper() else ord('a')
                plaintext += chr((ord(char) - base - shift) % 26 + base)
            else:
                plaintext += char
        print(f"Shift {shift:2d}: {plaintext}")

caesar_brute("Gur synt vf: synt{pnrfne_vf_rnfl}")

# Vigenere Cipher 解密
def vigenere_decrypt(ciphertext, key):
    plaintext = ""
    key_idx = 0
    for char in ciphertext:
        if char.isalpha():
            base = ord('A') if char.isupper() else ord('a')
            shift = ord(key[key_idx % len(key)].upper()) - ord('A')
            plaintext += chr((ord(char) - base - shift) % 26 + base)
            key_idx += 1
        else:
            plaintext += char
    return plaintext

# 频率分析
from collections import Counter
def freq_analysis(text):
    letters = [c.upper() for c in text if c.isalpha()]
    freq = Counter(letters)
    total = len(letters)
    for char, count in freq.most_common():
        print(f"{char}: {count/total*100:.1f}%")

4.2 RSA 挑战

# === RSA 基础知识 ===
# 公钥: (n, e)    n = p * q,  e 通常为 65537
# 私钥: d         d ≡ e^(-1) mod φ(n),  φ(n) = (p-1)(q-1)
# 加密: c = m^e mod n
# 解密: m = c^d mod n

# === 常见 RSA CTF 攻击 ===

from Crypto.Util.number import *
import gmpy2

# 1. 已知 p, q 直接解密
def rsa_decrypt(c, p, q, e=65537):
    n = p * q
    phi = (p - 1) * (q - 1)
    d = inverse(e, phi)
    m = pow(c, d, n)
    return long_to_bytes(m)

# 2. 小公钥指数攻击 (e=3, 明文小)
# 如果 m^e < n，则 c = m^e，直接开 e 次方根
def small_e_attack(c, e=3):
    m = gmpy2.iroot(c, e)[0]
    return long_to_bytes(int(m))

# 3. Wiener Attack (d 很小时)
# 使用连分数逼近 e/n ≈ k/d
# 工具: https://github.com/pablocelayes/rsa-wiener-attack

# 4. Fermat 分解 (p 和 q 接近时)
def fermat_factor(n):
    a = gmpy2.isqrt(n) + 1
    b2 = a * a - n
    while not gmpy2.is_square(b2):
        a += 1
        b2 = a * a - n
    b = gmpy2.isqrt(b2)
    return int(a - b), int(a + b)

# 5. 共模攻击 (同一明文，不同 e，相同 n)
def common_modulus(n, e1, e2, c1, c2):
    g, s1, s2 = gmpy2.gcdext(e1, e2)
    m = (pow(c1, s1, n) * pow(c2, s2, n)) % n
    return long_to_bytes(int(m))

import itertools
import string

target = "e99a18c428cb38d5f260853678922e03"  # md5("abc123")
charset = string.ascii_lowercase + string.digits

for length in range(1, 8):

Forensics 解题思维

取证题目的核心是仔细观察。不要忽视任何细节：

  • 文件大小异常大？可能有嵌入数据
  • 图片看起来正常？检查 LSB、EXIF、修改过的尺寸
  • ZIP 文件？可能有伪加密（修改标志位即可）
  • PCAP 文件？按协议分类逐一检查

# 模式 1: 字符比较 (最基础)

6.3 Ghidra 基本使用流程

# === Ghidra 逆向分析流程 ===

# 1. 创建项目 → 导入二进制文件
# 2. 自动分析 (Auto Analysis)
#    - 等待分析完成（进度条）
#    - 识别函数、交叉引用、字符串

# 3. 关键分析步骤:
#    a. Window → Defined Strings: 查看所有字符串
#       搜索 "flag", "correct", "wrong", "success"
#
#    b. 找到 main 函数:
#       Functions → 搜索 "main" 或 "entry"
#
#    c. 分析控制流:
#       反编译窗口查看伪代码
#       关注 if/else 分支（成功/失败条件）
#
#    d. 交叉引用 (Xref):
#       右键变量/函数 → References → Find references to
#
#    e. 重命名变量和函数:
#       提高可读性，便于分析

# 4. 动态验证:
#    根据分析结果构造输入
#    运行程序验证

# === GDB 动态调试 ===
# 安装 pwndbg 增强插件
gdb ./challenge

# 常用命令
(gdb) info functions            # 列出函数
(gdb) disas main               # 反汇编 main
(gdb) b *0x401234              # 设断点
(gdb) r                         # 运行
(gdb) ni                        # 单步（不进入函数）
(gdb) si                        # 单步（进入函数）
(gdb) x/20x $rsp              # 查看栈
(gdb) x/s 0x402000            # 查看字符串
(gdb) set $rax = 1            # 修改寄存器
(gdb) jump *0x401300          # 跳转执行

逆向是 CTF 中学习曲线最陡的方向之一。建议：

  • 从简单的 crackme 开始练习

CTF 竞赛道德准则
  • 不要攻击比赛基础设施（评分服务器、其他队伍等）
  • 比赛期间不要公开 Writeup 或 Flag
  • 不要使用他人的解题成果（除非是团队合作）
  • 赛后积极分享 Writeup，为社区做贡献
  • 尊重出题者，如发现非预期解及时通报
给新手的建议
  • 不要害怕失败：比赛中解不出题是正常的，重要的是赛后学习 Writeup
  • 记录笔记：建立自己的知识库，记录解题思路和工具用法
  • 找队伍：CTF 是团队运动，不同方向的队友互补很重要
  • 保持耐心：安全学习是长期积累的过程，不要急于求成
  • 动手实践：看十遍不如做一遍，多动手比什么都重要
